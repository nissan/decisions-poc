All three list zero output-token charges. List prices are not measured latency or cost; account minimums and gateway charges are separate. [OpenRouter lists Luna Decisions](https://openrouter.ai/openai/gpt-6-luna-decisions) and [Jev 1.14](https://openrouter.ai/typesafe/jev-1.14) as paid, not a free substitute. The OpenAI subscription benefit is not a free signup tier, and an interactive playground is not proof of reusable API access. No paid sign-up, top-up, auto-recharge, subscription linkage, or payment method is assumed authorized.

## Fair head-to-head

- Retain the rule baseline and synthetic corpus. Score the same three independent questions with equivalent instructions: lane selection (`choice`), task clarity (OpenAI `predicate`; Gemini/Jev `noul`), and ordered complexity (`score`). Use a single request per eligible case. The same local filter and recommendation policy applies to every arm. No account details, credentials, labels or production packets go to the models.
- Normalize answers, not distinct meanings of confidence. Compare `P(yes)` and the probability of the selected lane on common axes, retaining raw probability distributions and provider-native confidence. Pre-register shared primary thresholds; calibrate optional provider-specific thresholds only on development cases. Freeze the model IDs, contracts and settings before holdout.
- Report each provider versus the rule baseline and paired against the other providers on the same eligible cases. Label the transport separately: native Gemini and OpenAI versus gateway-hosted Jev. Do not attribute API round-trip differences solely to model inference. Record provider/endpoint, exact model, source hashes, attempted and metered counts, accuracy, coverage, abstentions, failures and measured usage separately from projected executor cost. Do not rank missing arms as losses.
- Authorities and checks: one synthetic development smoke per provider after verified account access; maintainer review of candidate labels and thresholds before live holdout. No provider fallback on a failed request. Do not publish a head-to-head result without all three measured arms.

Current implementation: rules and Gemini adapter only. OpenAI and Jev APIs are comparison scope, not implemented or verified by the CLI yet.
